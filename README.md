# CashPatch AI

CashPatch is an AI-assisted money-leak detection and recovery platform for small businesses.

This repository contains the Next.js application for the CashPatch MVP.

## Current MVP
- Supabase magic-link authentication
- RLS-isolated workspaces
- Recovery Queue
- CSV money-leak scan
- Deterministic scoring engine
- Stripe Checkout / Customer Portal / webhooks
- Standard and Pro subscription tiers

See `README.md` after the initial sync for full setup details.
